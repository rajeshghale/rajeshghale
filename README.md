## 🧠 About Me

I'm a **Bachelor of Computer Applications (BCA)** student at **Pokhara University**, focused on becoming a strong **front-end and full stack engineer**. My work centers on the **Next.js / React.js ecosystem**, building responsive, animation-rich, production-quality interfaces with **Tailwind CSS** and **GSAP**, and connecting them to real content backends like **Sanity CMS**.

I care about **clean architecture, performance, and shipping real projects** — not tutorials left half-finished. Alongside web development, I've also worked hands-on with **embedded systems (Arduino/C)**, which gave me an appreciation for how software meets hardware constraints.

I'm early in my career and building in public — every project in this profile is real, deployed, or actively in progress.

**🎯 Open To:** Front-End Internships · Full Stack Junior Roles · Open Source Collaboration · Freelance Web Projects

## 🚀 Featured Projects

<details>
<summary><b>🌐 Personal Portfolio Website</b></summary>
<br/>

A fully responsive personal portfolio built to showcase projects and skills, with a strong focus on motion and perceived performance.

| Aspect | Details |
|---|---|
| **Stack** | Next.js, GSAP, Tailwind CSS |
| **Rendering** | Server-side rendering for fast initial page loads |
| **Animation** | Scroll-triggered animations and page transitions via GSAP |
| **Deployment** | Vercel, with GitHub CI enabling instant preview deployments on every push |
| **Status** | Ongoing (2024 – Present) |

Built to be fast across devices while telling a visual story through motion rather than static sections — every scroll interaction was hand-tuned rather than using a template animation library.

</details>

<details>
<summary><b>🛒 E-Commerce Storefront</b></summary>
<br/>

A full-featured e-commerce frontend with a headless CMS backend for real content management.

| Aspect | Details |
|---|---|
| **Stack** | Next.js, React.js, Tailwind CSS, Sanity CMS |
| **Features** | Dynamic product routing, category filtering, client-side cart via React state |
| **Content** | Sanity CMS integration for structured product data and real-time updates without redeployment |
| **Responsiveness** | Fully responsive across mobile, tablet, and desktop viewports |
| **Status** | Ongoing (2024 – Present) |

The goal of this project was to decouple content from code — product data can be updated live through Sanity's studio without touching or redeploying the frontend.

</details>
